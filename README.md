# Class 10 Quiz App 📚

Quick, focused revision for Class 10 students — pick a subject and difficulty level, and get sharp!

## 🌐 Live Demo
[classx-quizapp.onrender.com](https://classx-quizapp.onrender.com)

## ✨ Features
- Multiple subjects (Biology, SST, and more)
- Difficulty levels: Easy, Medium, Hard
- Instant scoring and progress tracking
- High score tracking

## 🛠️ Built With
- Python (Flask)
- HTML/CSS/JavaScript
- Deployed on Render

## 🚀 Running Locally
```bash
git clone https://github.com/nahachandrima060/ClassX-QuizApp
cd ClassX-QuizApp
pip install -r requirements.txt
python app.py
